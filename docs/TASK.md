## 0. 목표 한 문단

정사면체 스핀체에 일축 이방성을 걸면 C₃축 선택 상의 유효 모형은 일반 XY–Ising 모형
H = −Σ⟨ab⟩[J₁σσ′ + (J₂ + J₄σσ′)cos(φ−φ′)] 이 된다 (강체 극한: J₁ = 160G/81, J₂ = 128G/81, J₄ = 512H₄/729, r = J₄/J₂ = (4/9)zH₄/zG).
해석 결과는 (i) r = 0과 J₂ → 0의 두 극한에서 정확히 분리되고 전이 순서가 반대, (ii) 결합 연산자 ε_σ(∂ψ)²의 차원이 3이라 무관 → 두 선은 **분리된 사중임계점에서 교차**, (iii) 교차점 r_× = 4.31, T_× = 7.07G (Yosefin–Domany형 분리 근사 + 정확한 임계 상관). 선행연구(Lee–Granato–Kosterlitz 1991, Yosefin–Domany 1985)는 이 선들이 어떻게 만나는지를 미해결로 남겼다. **T1은 이 교차를 열역학 극한에서 확정하는 것**, T2는 유효 모형이 전체 스핀체 모형을 대표함을 보이는 것이다.

## 1. 반드시 지킬 알고리즘 규칙 (예비 계산에서 얻은 교훈)

1. **클러스터 수는 고정한다.** "뒤집힌 사이트 합이 N이 될 때까지 클러스터 반복"은 상태 의존 정지 규칙이라 분포를 편향시킨다(6×6 Ising, T = 2.5: ⟨m²⟩ = 0.610, 정확값 0.5286). 클러스터 수는 열평형 전반부에만 조정하고 측정 중에는 고정한다. `tests/test_c3model.py::test_exact_ising_6x6`가 이것을 지킨다.
2. **ψ 틀 σ 클러스터를 반드시 포함한다.** ψ를 고정하고 (σ → −σ, φ → φ+π)를 뒤집는 클러스터는 결합 J₁ + J₂cosΔψ ≥ J₁ − J₂ > 0로 좌절이 없다. 이것 없이는 L = 64, r ≈ 4에서 Ising 자기상관이 190–1500 스윕이었고 평형에 도달하지 못했다(≈1 스윕으로 감소, 비용 +12%).
3. 평형 판정: 시계열 4등분 평균이 오차 내 일치, 무작위·정렬 두 초기 조건 일치, 병렬 템퍼링 왕복 ≥ 20회.

- **단위 테스트 (모두 통과해야 다음 단계)**

  - 순수 XY 극한(J₁ = J₄ = 0): L = 32, 64에서 Υ = 2T/π 교차가 Hasenbusch(2005) T_KT = 0.8929 J₂의 알려진 유한 크기 값과 일치. Weber–Minnhagen 맞춤 T_KT = 0.893 ± 0.01.
  - 순수 Ising 극한: Binder 교차 T = 2.269 J₁ ± 0.01, U* = 0.611.
  - 두 정확 분리 극한: r = 0 (σ와 φ 분리)와 J₂ = 0 (σ와 ψ 분리)에서 위 두 결과를 동시에 재현.
  - 회귀: `data/pilot_v3/`의 L = 32 결과를 오차 내 재현.

### N1. T1 주 계산: 교차점 (핵심)
| 항목 | 값 |
| --- | --- |
| 모형 | 강체 결합, 정사각 격자, 주기 경계. 단위 G = 1 |
| r | 3.6, 3.8, 4.0, 4.1, 4.2, 4.3, 4.4, 4.6, 4.8, 5.0 |
| L | 32, 48, 64, 96, 128 (128은 r = 4.0–4.6 우선) |
| 온도 | 각 r에서 T ∈ [T_c,min − 0.4, T_c,max + 0.5], 예비 계산 기준 6.2–8.0. 교환 수락 0.2–0.3이 되게 사다리 설계 (L = 64에서 등비 26개가 0.16–0.19) |
| 표본 | 열평형 ≥ 1000 스윕(전반부에 클러스터 수 조정), 측정 ≥ 20000 스윕. 예비 계산 τ_int ≈ 1–5 스윕 |
| 비용 | L = 64: 복제본당 약 4 ms/스윕(코어 1개). L = 128 r 하나 ≈ 50 복제본 × 16 ms × 21000 ≈ 4.7 코어-시간. 전체 대략 70 코어-시간. 실행 전 `tools`로 비용 추정을 다시 하고 우선순위대로 돌릴 것 |

측정량: σ Binder U₄, |m_σ|, Υ(φ 비틀기 = ψ 비틀기), M_φ = Σe^{iφ}, M_ψ = Σσe^{iφ}의 크기와 상관길이 비 ξ/L, 비열, 에너지 히스토그램.

**사전 등록 판정 규칙** (결과를 보기 전에 고정)
- T_I(r): Binder 교차의 L → ∞ 외삽 (교차점 이동 ∝ L^{−1/ν−ω}, 결합 ν 고정 1과 자유 둘 다 보고).
- T_KT(r): Weber–Minnhagen 맞춤 Υ(L)π/(2T) = 1 + 1/(2lnL + c)를 모든 L에 동시 적용, χ²/dof 최소인 T. 보조로 ξ_ψ/L 교차.
- 교차 확정: r ≤ 4.0에서 T_I − T_KT > 3σ, r ≥ 4.6에서 T_KT − T_I > 3σ, 그리고 ΔT(r)의 선형 맞춤 영점 r_×를 오차와 함께 보고.
- 분리 사중임계 확정: 교차점 양쪽(r = 4.2, 4.4)에서 Ising ν = 1 ± 0.1, U* = 0.61 ± 0.02, C_max ∝ ln L (L² 맞춤이 기각), 에너지 히스토그램 단봉.
- 1차 합류 판정: 이봉 히스토그램의 장벽 ΔF가 L과 함께 커지거나 C_max/L² → 상수. 하나라도 나오면 즉시 보고하고 멈춘다.
- 해석 예측 r_× = 4.31, T_× = 7.07과의 비교는 판정 후에 한다(맞추려고 분석을 바꾸지 않는다).

### N2. T1′: 뒤집힌 순서 영역
r = 5.0, 6.0에서 L = 32–96. σ 무질서 + ψ 준질서 구간이 L에 무관하게 남는지(Υ > 2T/π인 동안 U₄ → 0). φ(옥투폴)와 ψ(헥사데카폴)의 상관 지수 η가 다름을 보인다(ψ 구간에서 φ는 지수적 감쇠).

### N3. T2: 전체 스핀체 모형 (polyspin 확장)
- Paper I 저장소 `cywon-commits/Polyhedron_Spin_Group`의 `polyspin`에 단일 스핀 이방성 V = Σᵢ[a₂P₂(ẑ·Sᵢ) + a₄P₄(ẑ·Sᵢ)]를 **별도 브랜치**에서 추가한다. 기본값 a₂ = a₄ = 0이며, Paper I의 기존 테스트 전체가 그대로 통과해야 한다. 병합 후 태그(예: `v0.2.0-aniso`)를 달고 이 저장소는 그 태그를 고정 의존성으로 쓴다(`pyproject.toml`의 `fullmodel` 추가 의존성).
  - 고칠 곳: `model.py`(energy_total, spin_energy, cluster_inter_energy 경로의 단일 스핀 항), `moves.py`(강체 회전·겹침 이동의 ΔE), `groundstate.py`(이방성 포함 단일 스핀체 최소화), `run.py`(키 a2, a4).
  - 테스트: 국소 ΔE 대 전체 재계산(1e-11), 단일 체 최소화가 Γ 공식 E_eff = −ΓΣn⁴, Γ = (35/9)a₄ + 2a₂²(3/λ_E − 1/λ_T₂)를 1% 이내로 재현(`reference/twobody_relaxation.py`, 노트 2–4절), 2-디자인 성질(a₄ = 0이면 1차에서 방향 무관).
- 관측량: 각 체의 실험실 z축에 대한 다중극 q₃₀(σ), q₃₃(e^{iφ}), q₄₃(e^{iψ}), 축 선택 지표 K = Σn_α⁴. KT 기준은 체 각도 α 비틀기 강성 ρ_α = 9ρ_ψ이므로 ρ_α = 18T/π.
- 매개변수: J = 1, K = 2, zG = 0.08, a₂ = 0, a₄ = −0.02, zH₄ ∈ {0.72, 0.80, 0.88}. 이 점들에서 T 상이 바닥상태이고(T–Sq 경계 zH₄ = 0.692K + 0.923zG = 1.458보다 아래), 완화 포함 r_eff ≈ 3.6, 4.05, 4.5로 교차점을 가로지른다. **먼저** 각 점의 r_eff를 `reference/twobody_relaxation.py` 방식으로 다시 계산해 보고할 것. 예상 T_× ≈ 0.14 J.
- L = 16, 24, 32 (가능하면 48). 판정: 유효 모형의 (r_eff, T)에 사상했을 때 T_I, T_KT의 순서와 교차 위치가 N1 결과와 오차 내 일치.
