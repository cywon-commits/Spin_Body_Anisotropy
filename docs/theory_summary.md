# 이론 요약 — 예측식과 근거 등급

자세한 유도는 `docs/note/anisotropy_selection_note.pdf`. 등급: [증명] 해석, [수치확인] 오차와 함께 확인, [추측].

## 축 선택
- P1 [증명] 정사면체는 구면 2-디자인이라 Σᵢ(ẑ·Sᵢ)² = 4/3: a₂의 1차 기여 0.
- P2 [증명, 수치확인 <1%] E_eff(n̂) = −Γ Σ_α n_α⁴, Γ = (35/9)a₄ + 2a₂²(3/λ_E − 1/λ_T₂). Γ > 0 → S₄ ∥ z, Γ < 0 → C₃ ∥ z. D 부호와 무관.
  λ_E = (8/3)Φ″(−1/3), λ_T₂ = (8/9)[3Φ′(−1/3) + 2Φ″(−1/3)].
- P3 [증명] 3λ_T₂ − λ_E = (8/27)(27κ₁ − 63κ₃ + 35κ₄) = (8/27)(27J + 9zG − 8zH₄): κ₂ 상쇄.

## 유효 모형 (강체 극한) [증명, 수치확인 기계 정밀도]
- S₄ ∥ z: θ = 2α, H = −Σ[(32/9)G cosΔθ + (32/81)H₄ cos2Δθ] (일반화 XY, q = 2).
- C₃ ∥ z: H = −Σ[J₁σσ′ + (J₂ + J₄σσ′)cosΔφ], J₁ = 160G/81, J₂ = 128G/81, J₄ = 512H₄/729.
  ψ 틀: H = −Σ[J₁σσ′ + (J₄ + J₂σσ′)cosΔψ], e^{iψ} = σe^{iφ}. Granato 등의 (A, B, C) = (J₄, J₂, J₁).
- 강성은 등방(Schur): ρ = 128G/9 + 512H₄/81 (S₄, C₃ 동일).

## 교차
- P6 [수치확인 r ≤ 2, 단 편향된 구 코드 — 재확인 필요] σ 질서 영역 T_KT ≈ 0.893(J₄ + J₂⟨σσ′⟩).
- P7 Ising 선 T_I ≈ 2.269(J₁ + J₂⟨cosΔψ⟩).
- P8 [해석] 교차점에서 ⟨σσ′⟩ = 1/√2 (정확), ⟨cosΔψ⟩ = 0.723 (2D XY의 T_KT, Wolff MC) →
  T_× = 2.269(J₁ + 0.723J₂) = 7.07G, r_× = T_×/(0.893J₂) − 1/√2 = 4.31.
  (방법은 Yosefin–Domany 1985 Sec. IV A의 분리 변분 근사를 A ≠ B로 일반화한 것.)
- P9 [증명: 선형 RG] 결합 연산자 ε_σ(∂ψ)²의 차원 1 + 2 = 3 > 2 → 무관. 분리된 사중임계 교차, 합류 아님.
  KT 선은 ⟨σσ′⟩를 통해 t ln|t| 꼬임을 물려받는다.
- P10 [추측] 유효 모형 적용 조건: ℓ_Γ ≲ 1 (|Γ| ≳ ρ), ℓ_Γ = √(ρ/|Γ|).
  근거: 체의 다른 C₃/C₂ 축 둘레 결함은 축을 기울이므로 길이 ℓ_Γ의 끈에 갇힌다. ℓ_Γ가 격자 간격보다 길면 가둠이 듣지 않아 축 기울기 요동과 결함이 전이를 바꾼다.
  (이전 판의 "Γ* ≈ ρ e^{−2πρ/T}, 사실상 모든 Γ에서 유효 모형 성립"은 스핀파만 본 논증으로 결함을 빠뜨려 틀렸다. N3: ρ ≈ 1.55 J, |Γ| = 0.078, ℓ_Γ ≈ 4.5에서 전체 모형 T_c가 유효 모형보다 약 40% 낮음, docs/N3_report.md. 2026-11-12 수정.)

## 강체 근사 보정 [수치확인]
두 체 완화 계산(K = 0.5, zG = 1): H₄ = 0에서 δJ₄/J₂ = −0.04, δJ₁, δJ₂는 0.1–0.2%. 물리적 창(K = 2) 안에서 r_eff ≈ 0.94 r_rigid, J₁/J₂ = 1.155 → 교차점 r_× ≈ 4.07.

## 물리적 창 [수치확인 + 경계식]
T–Sq 경계 zH₄ = 0.692K + 0.923zG. r = r_× 선(zH₄/zG ≈ 10)에서 K ≤ 2이면 zG < 0.079K.
Sq 상: 두 반평행 쌍이 직교, M = 0, 안정화군 D₄h, π₁ = 2D₄. Paper I 물리 평면(K = 0.5)에도 쐐기로 존재.
