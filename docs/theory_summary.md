# 이론 요약 — 예측식과 근거 등급

자세한 유도는 `docs/note/anisotropy_selection_note.pdf`. 등급: [증명] 해석, [수치확인] 오차와 함께 확인, [추측].

## 축 선택
- P1 [증명] 정사면체는 구면 2-디자인이라 Σᵢ(ẑ·Sᵢ)² = 4/3: a₂의 1차 기여 0.
- P2 [증명, 수치확인 <1%] E_eff(n̂) = −Γ Σ_α n_α⁴, Γ = (35/9)a₄ + 2a₂²(3/λ_E − 1/λ_T₂). Γ > 0 → S₄ ∥ z, Γ < 0 → C₃ ∥ z. D 부호와 무관.
  λ_E = (8/3)Φ″(−1/3), λ_T₂ = (8/9)[3Φ′(−1/3) + 2Φ″(−1/3)].
- P3 [증명] 3λ_T₂ − λ_E = (8/27)(27κ₁ − 63κ₃ + 35κ₄) = (8/27)(27J + 9zG − 8zH₄): κ₂ 상쇄.

## 유효 모형 (강체 극한) [증명, 수치확인 기계 정밀도]
- S₄ ∥ z: θ = 2α, H = −Σ[(32/9)G cosΔθ + (32/81)H₄ cos2Δθ] (일반화 XY, q = 2).
- C₃ ∥ z: H = −Σ[J₁σσ′ + (J₂ + J₄σσ′)cosΔφ], J₁ = 160G/81, J₂ = 128G/81, J₄ = 512H₄/729.
  ψ 틀: H = −Σ[J₁σσ′ + (J₄ + J₂σσ′)cosΔψ], e^{iψ} = σe^{iφ}. Granato 등의 (A, B, C) = (J₄, J₂, J₁).
- 강성은 등방(Schur): ρ = 128G/9 + 512H₄/81 (S₄, C₃ 동일).

## 교차
- P6 [수치확인 r ≤ 2, 단 편향된 구 코드 — 재확인 필요] σ 질서 영역 T_KT ≈ 0.893(J₄ + J₂⟨σσ′⟩).
- P7 Ising 선 T_I ≈ 2.269(J₁ + J₂⟨cosΔψ⟩).
- P8 [해석] 교차점에서 ⟨σσ′⟩ = 1/√2 (정확), ⟨cosΔψ⟩ = 0.723 (2D XY의 T_KT, Wolff MC) →
  T_× = 2.269(J₁ + 0.723J₂) = 7.07G, r_× = T_×/(0.893J₂) − 1/√2 = 4.31.
  (방법은 Yosefin–Domany 1985 Sec. IV A의 분리 변분 근사를 A ≠ B로 일반화한 것.)
- P9 [증명: 선형 RG] 결합 연산자 ε_σ(∂ψ)²의 차원 1 + 2 = 3 > 2 → 무관. 분리된 사중임계 교차, 합류 아님.
  KT 선은 ⟨σσ′⟩를 통해 t ln|t| 꼬임을 물려받는다.
- P10 [추측] 유효 모형은 ⟨θ²⟩ → 0 극한에서 정확하고, 선행 보정은 결합의 Debye–Waller 인자다 (θ: C₃ 축의 기울기). 작은 θ에서 체당 (l, m) 성분이 1 − [l(l+1) − m²]θ²/4로 줄고 결합은 두 체를 거치므로 J₁ × (1 − 6⟨θ²⟩), J₂ × (1 − 1.5⟨θ²⟩), J₄ × (1 − 5.5⟨θ²⟩). C₃ 축 근처에서 K − 1/3 = (4/3)θ². 가우스 기울기 이론을 전이점에서 자기 일관되게 풀면 a = T_eff/ρ, g(ℓ_Γ) = ρ∫_BZ d²k/(2π)² · 2/(ρk̂² + 8|Γ|/3) (ℓ_Γ = √(ρ/|Γ|); 큰 ℓ_Γ에서 g ∝ ln ℓ_Γ), κ = T_eff를 정하는 결합의 DW 계수일 때 ⟨θ²⟩ = a·g/(1 + a·κ·g), T_c = T_eff(1 − κ⟨θ²⟩). 직접 측정한 C₃ 축 기울기(N3e)는 이 가우스 값보다 크다: ℓ_Γ = 0.77에서 1.28배, 4.46에서 1.84배. 따라서 이 식은 정성적 경향(로그 수렴)만 준다. 선형 인자 1 − κ⟨θ²⟩는 κ⟨θ²⟩ ≲ 0.2에서 전체 모형 T_c를 5% 안에서 재현하고, κ⟨θ²⟩ ≈ 0.6 (s = 1)에서는 과보정한다 (docs/N3e_report.md). a는 유효 모형만으로 정해지고 N3s 범위에서 거의 일정 (0.090–0.091)하므로 수렴은 ℓ_Γ에 로그다. 이전 판의 "결함 가둠이 주원인 (적용 조건 ℓ_Γ ≲ 1)"은 N3s 자료로 지지되지 않는다 (docs/N3s_report.md; 2026-11-13 수정, 시험은 docs/N3d_analysis_plan.md).
- P11 [증명] Debye–Waller 계수와 채널의 기울기 민감도. 체를 축 n̂ ⊥ ẑ 둘레로 θ만큼 돌리면 l차 다중극의 (l, m) 성분은 Wigner d^l_{mm}(θ) = 1 − [l(l+1) − m²]θ²/4 + O(θ⁴)배가 되고, m ± 1로 새는 성분은 θ의 1차지만 기울기 방위각 평균에서 결합(두 체의 곱)에 기여하지 않는다 (서로 독립인 방위각 가정). 따라서 두 체를 거치는 결합의 인자는 1 − ½[l(l+1) − m²]⟨θ²⟩다: J₁ (l = 3, m = 0) 6, J₂ (l = 3, |m| = 3) 1.5, J₄ (l = 4, |m| = 3) 5.5. 같은 l에서 |m| = l 채널이 가장 둔감하고(계수 l/2) m = 0 채널이 가장 민감하다(계수 l(l+1)/2). 즉 기울기 요동은 축 방향 다중극(σ를 정하는 q₃₀)을 가장 크게, 평면 내 다중극(q₃₃)을 가장 작게 줄인다.

## 강체 근사 보정 [수치확인]
두 체 완화 계산(K = 0.5, zG = 1): H₄ = 0에서 δJ₄/J₂ = −0.04, δJ₁, δJ₂는 0.1–0.2%. 물리적 창(K = 2) 안에서 r_eff ≈ 0.94 r_rigid, J₁/J₂ = 1.155 → 교차점 r_× ≈ 4.07.

## 물리적 창 [수치확인 + 경계식]
T–Sq 경계 zH₄ = 0.692K + 0.923zG. r = r_× 선(zH₄/zG ≈ 10)에서 K ≤ 2이면 zG < 0.079K.
Sq 상: 두 반평행 쌍이 직교, M = 0, 안정화군 D₄h, π₁ = 2D₄. Paper I 물리 평면(K = 0.5)에도 쐐기로 존재.
