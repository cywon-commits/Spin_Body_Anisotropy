# N2 분석 계획 — 사전 고정 (2026-11-06, N2 생산 실행 전)

TASK.md N2: r = 5.0, 6.0에서 L = 32–96. σ 무질서 + ψ 준질서 구간이 L에 무관하게 남는지(Υ > 2T/π인 동안 U₄ → 0), 그리고 φ(옥투폴)와 ψ(헥사데카폴)의 상관 지수 η가 다름(ψ 구간에서 φ는 지수적 감쇠)을 보인다. TASK에 구체적 판정 기준이 없어서, 생산 데이터를 보기 전에 아래와 같이 고정한다. 평형 기준과 오차 방법은 N1과 같다 (`docs/N1_analysis_plan.md` 3, 5절; `analysis.equilibration_check`).

## 1. 사다리와 실행
- **예비 실행:** L = 32, r = 5.0 (6.5–8.7, 40개)과 r = 6.0 (6.8–9.9, 48개)에서 열평형 1000 + 측정 5000 스윕 (`configs/n2/pilot/`). 여기서 쓰는 것은 C(T)와 대략의 전이 위치뿐이며, 판정에는 쓰지 않는다.
- **온도 범위 [T_I − 0.4, T_KT,L=32 + 0.5]:**
  - r = 5.0: 6.75–8.45 (N1의 T_I = 7.16, L = 32 Υ 교차 7.93)
  - r = 6.0: 7.0–9.75 (L = 32에서 C 봉우리 7.40, Υ 교차 9.24)
- **사다리:** `scripts/design_ladder.py`로 설계한다. 가우스 근사의 수락률 erfc(Δβσ_E/2)가 이웃 쌍마다 같아지도록 온도를 놓는다.
  - C(T)는 예비 실행 값에 ln L 증가 여유 1 + 0.21 ln(L/32)를 곱해 쓴다.
  - 복제본 수는 `configs/T1_runs.csv`의 값(14/20/26/38)을 그대로 쓴다. 설계상 최소 필요 수(r = 5.0: 9/14/18/28, r = 6.0: 12/18/24/36)보다 모두 크므로, 예측 수락률은 모든 쌍에서 0.3 이상이다.
  - 예측식은 측정과 맞는다 (N1 r = 5.0, L = 96: 예측 최소 0.342 대 측정 0.342).
- **생산 실행:** r ∈ {5.0, 6.0} × L ∈ {32, 48, 64, 96}, 열평형 1000 + 측정 20000 스윕, 클러스터 3종, 무작위 시작.
- **정렬 시작 대조:** r = 6.0, L = 64 하나 (구간이 가장 넓어 준안정 위험이 가장 큰 곳).

## 2. 판정량과 기준
재가중은 각 r의 온도 범위 전체에서 0.005 간격으로 하고, 오차는 크기별 결합 블록 잭나이프로 구한다 (N1과 같음).

**(A) 구간의 존재.**
- T_I(r): Binder 교차의 외삽 (N1 주 방법, x = 2.75).
- T_KT(r): 모든 L의 Υ에 동시 Weber–Minnhagen 맞춤 (보정 없음. WM 편향 −0.25%는 구간을 좁히는 방향이라 보수적이다).
- 기준: T_KT − T_I > 3σ.

**(B) 구간이 L에 무관하게 남음.** 판정 온도는 구간 안쪽의 세 점 T_q = T_I + q (T_KT − T_I), q = 0.25, 0.5, 0.75다 (판정량의 중심값으로 정함). 각 T_q에서 다음을 모두 요구한다.
1. **σ 무질서:** U₄(L)가 L에 따라 감소한다. L = 32와 L = 96의 차이 U₄(32) − U₄(96) > 3σ. 그리고 U₄(96) < U₄(32)/2.
2. **ψ 준질서:** 모든 L에서 Υ(L) > 2T/π이고, 가장 작은 여유 Υ − 2T/π가 3σ보다 크다.

**(C) φ와 ψ의 상관 지수.** χ_X(L) = ⟨|M_X|²⟩/N (X = ψ, φ)를 ln χ = (2 − η_X) ln L + b로 맞춰 유효 지수 η_X를 각 T_q에서 구한다 (4개 L 전부, 잭나이프 오차). 다음을 모두 요구한다.
1. **ψ는 KT 준질서:** 0 ≤ η_ψ ≤ 0.25 + 3σ.
2. **φ는 지수 감쇠:** η_φ − η_ψ > 3σ, η_φ > 1. 지수 감쇠면 χ_φ가 L에 무관해지므로 유효 η_φ → 2가 된다.
3. **보조:** ξ_φ/L이 L에 따라 감소한다 (ξ_φ 유한). 판정에는 쓰지 않는다.

**(D) 평형.** 모든 실행이 `equilibration_check`를 통과해야 한다. 정렬 시작 대조는 무작위 시작과 N1과 같은 기준(max|z| < 4, χ²/자유도 < 2)으로 일치해야 한다.

**결론 규칙.** r마다 (A), (B)의 세 T_q, (C)의 세 T_q가 모두 통과하면 "뒤집힌 순서 구간 확인"으로 판정한다. 하나라도 실패하면 실패한 항목과 함께 보고하며, 기준을 사후에 바꾸지 않는다.
