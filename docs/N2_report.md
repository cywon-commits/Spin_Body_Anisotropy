## 3. 보조 분석 (사전 등록 아님): r = 5.0, q = ¼의 실패 원인
**도입 이유:** 사전 기준 하나가 근소하게 실패해(0.526 대 0.5), 실패가 σ 질서의 잔존 때문인지 유한 크기 때문인지 구별하려고 추가했다. 판정은 바꾸지 않는다.

- q = ¼에서 ξ_σ/L이 L에 따라 0.57 → 0.27로 빠르게 줄고, ξ_σ 자체는 포화하는 중이다 (증가폭 3.8 → 1.8 → 1.6). 무질서 상의 유한 상관길이 ξ_σ ≈ 26–28에 수렴하는 모양이다 [수치확인].
- 같은 조건에서 L/ξ_σ ≈ 3.8 (L = 96)이라 U₄가 아직 0으로 충분히 떨어지지 않았다. 기준 "U₄가 L = 32 → 96에서 절반 이하"는 ξ_σ ≲ 20인 온도에서만 의미가 있었다. 사전 기준이 T_I에 너무 가까운 온도를 포함했다고 판단한다 [추측: L ≥ 192 계산으로 확인 가능].
- q = ½, ¾에서는 ξ_σ가 이미 L과 무관하게 포화했다 (13, 8.8).
