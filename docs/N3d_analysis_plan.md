## 4. 판정과 보고
- **T_eff^R(s):** max(T_I, T_KT). T_I는 Binder 외삽 (x = 2.75), T_KT는 WM이다. N1, N3s와 같은 방법이며, 결합 잭나이프 오차를 쓴다.
- **판정 (의뢰자 지정):** 네 s 모두 |T_Υ^full / T_eff^R − 1| ≤ 0.05이면 "Debye–Waller 보정 유효 모형이 전체 모형을 대표"로 판정한다.
  - T_Υ^full은 N3s의 L = 24 무작위·정렬 평균이다.
  - 오차는 두 시작 폭의 절반에 T_eff^R 오차를 더한다.
  - 판정은 중심값으로 한다.
- **민감도 (같은 L 비교):** 유효 모형 L = 16, 24의 Υ = 2T/π 교차를, 같은 L의 전체 모형 T_Υ (무작위·정렬 각각과 평균)와 비교한다.
- **보조 (판정 아님):** 가우스 기울기 이론 ⟨θ²⟩ = T ∫_BZ d²k/(2π)² · 2/(ρ k̂² + 8|Γ|/3)를 측정 ⟨θ²⟩와 비교한다. 격자 k̂² = 4 − 2cos k_x − 2cos k_y, T = T_Υ^full, ρ = 128G/9 + 512H₄/81 (강체)이다.
