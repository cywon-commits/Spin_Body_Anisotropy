# 예비 계산 보고 (채팅, 2026-11-04)

## 결론
두 선은 r = 4.1과 4.4 사이에서 분리된 채 교차하며, 1차 합류의 징후는 없다 [수치확인, 예비 L ≤ 64].
해석 예측 r_× = 4.31, T_× = 7.07이 그 사이에 놓인다. 알고리즘 교훈 두 가지는 본 계산의 필수 조건이다.

## 설정
C₃ 유효 모형, 강체 결합(G = 1), 정사각 격자, L = 32, 48, 64. 병렬 템퍼링 복제본 14/20/26, T = 6.3–8.0 등비.
갱신: Metropolis + σ(φ 틀) + σ(ψ 틀) + φ 클러스터, 클러스터 수는 열평형 전반부에 조정 후 고정.
열평형 1000 + 측정 10000 스윕. 데이터 `data/pilot_v3/`, 요약 `summary.jsonl`, 그림 `figures/pilot_crossing_v3.png`.

## 알고리즘 교훈
1. **정지 규칙 편향.** "뒤집힌 합이 N이 될 때까지 클러스터"는 편향된다. 6×6 Ising(T = 2.5) 정확해 E/N = −1.2801, ⟨m²⟩ = 0.5286에 대해 그 규칙은 −1.396, 0.610, 고정 개수는 −1.2797, 0.5286 (`reference/stopping_rule_bias_demo.py`). 이 규칙으로 얻은 이전 결과(채팅의 담금질 MC, 노트 6절 표, 예비 v1·v2)는 폐기한다. L = 32–64 근임계 영역에서는 v2와 v3 차이가 0.05 이하로 작았지만, 작은 계와 순수 XY 검증에서는 크다(r = 0의 KT 1.46 대 정확값 1.41).
2. **ψ 틀 σ 클러스터.** φ 고정 σ 클러스터(결합 J₁ + J₄cosΔφ)는 r ≳ 1에서 좌절되어 L = 64 Ising 자기상관이 190–1500 스윕이었고 v1은 평형에 이르지 못했다. ψ 고정 클러스터(결합 J₁ + J₂cosΔψ > 0)를 넣으면 약 1 스윕.
