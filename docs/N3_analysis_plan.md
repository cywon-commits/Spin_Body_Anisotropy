## 2. 판정과 특성화
**(1) TASK 판정: 유효 모형과의 일치.**
- 각 점에서 유효 모형의 T_I, T_KT를 N1과 같은 방법으로 구한다 (Binder 외삽 x = 2.75, WM).
- 전체 모형의 T_I, T_KT도 같은 방법으로 구한다. Υ는 ρ_α/9를 쓴다.
- 일치 기준 (모두 만족해야 일치):
  - 각 점에서 T_I − T_KT의 부호가 같다.
  - |T_I^full − T_I^eff|와 |T_KT^full − T_KT^eff|가 각각 3σ 이내다.
  - 교차 위치: ΔT의 부호가 바뀌는 zH₄ 구간이 같다.
- 전체 모형이 1차 전이이면 Binder 교차와 WM 맞춤은 정의상 적용할 수 없다. 이 경우 (1)은 "불일치(전이의 성격이 다름)"로 판정하고, 비교는 전이 온도(C 최댓값)와 유효 모형 T_I, T_KT 사이에서 한다.

**(2) 전이가 하나인지 둘인지.** 가장 큰 L에서 다음 셋이 서로 3σ 안에 있으면 "공동 전이"로 본다.
- U₄ 크기 쌍 교차들의 평균
- Υ = 2T/π 교차
- C 최댓값 온도

**(3) 1차 전이 판정** (N1의 1차 합류 판정과 같은 기준). 하나라도 성립하면 1차로 판정한다.
- 가장 큰 L에서 C 최댓값 온도의 재가중 에너지 히스토그램이 이봉(비 < 0.8)이고, 장벽 ΔF = ln(P_max/P_min)이 L과 함께 증가.
- C_max = a + bL² 맞춤이 기각되지 않고 (p ≥ 0.01) ln L 맞춤이 기각 (p < 0.01).
- U₄의 최솟값이 음수이고 L과 함께 더 깊어짐 (보조).

**(4) 축 선택.** 전이 바로 위와 아래에서 ⟨K⟩를 보고한다. 1/3에 가까울수록 유효 모형의 전제가 성립한다.

**(5) 평형.** `equilibration_check`를 적용한다. 1차 전이에서 PT 왕복이 기준(≥ 20)에 못 미칠 수 있다. 그 경우 그 실행의 판정량은 [추측] 등급으로 낮추고, 무작위·정렬 시작 비교로 보완한다.
