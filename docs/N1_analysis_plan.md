# N1 분석 계획 — 사전 고정 (2026-11-05, N1 데이터 생성 전)

이 문서는 N1 생산 데이터를 보기 전에 고정한 분석 절차다. TASK.md 2절 N1의 판정 규칙을 바꾸지 않는다. 다만 N0에서 확인한 Weber–Minnhagen 편향을 어떻게 적용할지 정하고, 보조 지표를 추가한다. 의뢰자 검토(2026-11-05)에 따른 것이며, N1 보고서에 이 문서를 그대로 인용한다.

## 1. Weber–Minnhagen 편향의 처리
N0에서 L = 16–64의 WM 맞춤은 순수 XY와 두 분리 극한에서 T_KT를 참값보다 약 0.25% 낮게 주었다 (0.8903–0.8909 대 0.8929, `docs/N0_report.md` 3.1절) [수치확인]. 이 값을 계통 오차 ε_WM = 0.0025·T_KT로 둔다.

| 판정 | 적용 |
| --- | --- |
| r ≤ 4.0: T_I − T_KT > 3σ | T_KT를 (1 + 0.0025)배로 올린 값으로 검사한다 (보수적: 편향이 Ising 위 판정을 쉽게 만드는 방향이므로 제거) |
| r ≥ 4.6: T_KT − T_I > 3σ | 보정 없이 검사한다 (편향이 이미 이 판정에 불리한 방향) |
| r_× (ΔT(r) 선형 맞춤의 영점) | 통계 오차와 계통 오차를 따로 보고: r_× = 값 ± (통계) ± (계통). 계통은 T_KT를 0과 +0.25% 보정한 두 분석의 r_× 차이 |
| T_× | r_×와 같은 방식으로 (통계) ± (계통) |

σ는 T_I와 T_KT 오차의 제곱합 제곱근이다 (서로 다른 관측량이지만 같은 실행에서 나오므로 잭나이프 블록을 같이 지워 공분산까지 넣는다).

## 2. 보조 지표: ξ_ψ/L 교차
- ψ = e^{iψ} 장의 2차 모멘트 상관길이 비 ξ_ψ/L (`analysis.xi_crossing`, 관측량 `xiL_psi`). 크기 쌍마다 교차 온도와 교차점의 ξ_ψ/L 값을 보고한다.
- 비교 기준: XY 모형 KT 점의 ξ₂nd/L ≈ 0.7507 (Hasenbusch 2005, L → ∞).
- 용도: 교차 확인용이며 판정에는 쓰지 않는다. WM T_KT와 ξ_ψ/L 교차 온도가 크게 어긋나면(> 3σ + ε_WM) 보고서에 적고 원인을 찾는다.

## 3. 평형·사다리 기준 (TASK.md 1절과 일치)
- 교환 수락률은 시도당 정의로 모든 이웃 쌍에서 ≥ 0.2이어야 한다. 미달하면 그 실행은 판정에 쓰지 않고 사다리를 다시 설계해 재실행한다.
- 완전 왕복(아래 → 위 → 아래) ≥ 20회.
- 평형 판정은 `analysis.equilibration_check`의 네 조건(4등분 검사, 블록 길이 ≥ 10 τ_int 즉 τ_int ≤ n_meas/200, 완전 왕복 ≥ 20, 시도당 교환 ≥ 0.2)을 모두 만족해야 한다. 4등분 검사만으로는 음성 대조(ψ 틀 σ 클러스터 없음)를 잡지 못해 블록 길이 조건을 추가했다 (N0 보고서 부록, `tests/test_equilibration_control.py`).
- 무작위·정렬 시작 일치: 교차점 양쪽 (r = 4.2, 4.4)의 L = 64에서 정렬 시작 실행을 추가로 돌려 비교한다.
- 피팅에 쓰는 모든 온도의 τ_int를 보고한다.

## 4. 실행 순서
`configs/T1_runs.csv`의 우선순위(1 → 2)와, 같은 우선순위 안에서는 작은 L부터 실행한다. 비용 추정은 `scripts/estimate_cost.py`로 실행 전에 다시 계산했다 (N1 보고서에 기록).
