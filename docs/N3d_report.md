# N3d 보고: Debye–Waller 보정 유효 모형 (2026-11-13)

## 결론
- **사전 등록 판정: 충족.** C₃ 축 기울기 요동의 Debye–Waller 인자로 결합을 줄인 유효 모형의 전이 온도가 네 s 모두에서 전체 모형과 5% 이내로 맞는다.
  - R = T_Υ^full / T_eff^R = 1.010 ± 0.002, 0.984 ± 0.003, 0.969 ± 0.010, 0.962 ± 0.039 (s = 1, 0.3, 0.1, 0.03)
  - 보정 전 R은 0.603, 0.692, 0.773, 0.866이었다.
  - 판정: "Debye–Waller 보정 유효 모형이 전체 모형을 대표" [추측: 전체 모형이 평형 기준 미달이라 오차는 두 시작 폭의 절반. 유효 모형 실행 16개는 모두 평형 통과].
- **주의 1, 민감도가 기준선 근처다.**
  - K의 기준점을 T = 0 바닥상태 K₀(정적 변형 포함)로 바꾸면 R = 0.948, 0.944, 1.024, 1.007이 되어, s = 1과 0.3이 5% 경계를 근소하게 벗어난다.
  - 같은 L 비교에서는 s = 0.03, L = 24가 0.935다.
  - 보정의 크기(최대 40%)에 비하면 남는 차이는 작지만, 5% 수준의 일치는 θ² 추정 방식에 민감하다.
- **주의 2, 독립 예측이 아니다.** ⟨θ²⟩는 전체 모형에서 잰 ⟨K⟩로 정했다. 이 시험이 보인 것은 "측정된 기울기 요동을 Debye–Waller 인자로 넣으면 결손 전체가 설명된다"는 것이다. 기울기 요동을 독립적으로 예측하는 가우스 이론은 s = 0.03에서만 측정과 맞는다 (3절).
- **부수 발견 [수치확인, 유효 모형].** 보정 결합의 유효 모형은 네 s 모두 Ising과 KT 전이가 매우 가깝다.
  - T_I^R − T_KT^R = +0.0033 (4%), +0.0006 (2%), +0.0001 (1%), +0.000003 (0.07%)
  - 전체 모형에서 σ와 ψ 질서가 사실상 함께 나타난 것(N3, N3s)과 정합적이다. 보정이 r를 2.4–4.1, J₁/J₂를 0.63–1.13으로 옮겨 놓으면서 두 선이 붙는다.

판정 기준은 `docs/N3d_analysis_plan.md` (생산 전 `f591455`로 커밋, L = 16 예비 결과를 본 사실을 공개함), 분석은 `scripts/n3d_analysis.py`, 결과는 `data/n3d/n3d_summary.json`, 그림은 `figures/n3d_ratio.png`다.

같은 L에서도 일치 정도는 비슷하다. 다만 s가 작을수록 비가 1보다 작아지는 경향이 남는다 (L = 24의 s = 0.03은 6.5% 낮음). 무작위 시작의 얼어붙은 σ 영역이 전체 모형의 T_Υ를 낮추는 효과가 가장 큰 곳이다. 정렬 시작만 쓰면 s = 0.03, L = 24에서 0.003824 / 0.003823 ≈ 1.00이다.

**K 기준점:** 바닥상태 K₀ = 0.340, 0.339, 0.324, 0.324 (이방성에 의한 정적 변형과 축 정의의 효과)를 기준으로 하면 ⟨θ²⟩ = 0.083, 0.060, 0.050, 0.027이다. T_eff^R를 지배하는 결합(여기서는 모두 T_I이므로 J₁) 인자의 변화로 1차 추정하면 R = 0.948, 0.944, 1.024, 1.007이다. 정밀한 결론에는 정적 변형과 열적 기울기를 분리한 θ² 추정이 필요하다.

- 가우스 이론은 ℓ_Γ < 1 (s = 0.03)에서만 측정과 맞는다. ℓ_Γ가 클수록 측정 요동이 이론보다 크다 (s = 1에서 1.9배). 큰 기울기에서의 비조화 효과와 결함이 더하는 요동으로 본다 [추측].
- 전이점의 T/ρ는 0.054 → 0.079로 s와 함께 약 50% 변한다. 수정된 P10의 "T/ρ가 거의 일정" 가정은 이 범위에서 정확하지 않다. 로그 수렴 서술 자체는 유지하되 이 점을 덧붙일 것을 권한다 (P10은 의뢰자 문구대로 두었다).

## 4. 남은 일과 제안
- **독립 예측:** ⟨θ²⟩를 전체 모형에서 재지 않고 예측하려면, 가우스 이론에 비조화·결함 보정이 필요하다. 아니면 기울기 자유도를 포함한 자기 일관 계산 (T_c와 ⟨θ²⟩(T_c)를 함께 푸는 것)이 필요하다.
- **정적 변형 분리:** ⟨K⟩ − K₀(T) 대신 체 프레임에서 정의한 기울기 각을 직접 재면 기준점 민감도가 없어진다. 측정 코드에 체의 C₃ 축 방향을 추가하면 된다.
- **원고 서술 제안:** "전체 모형의 전이 온도는 체 사이 결합에 C₃ 축 기울기의 Debye–Waller 인자를 곱한 유효 모형으로 4% 안에서 재현되며 (ℓ_Γ = 0.8–4.5), 보정 없는 유효 모형은 ⟨θ²⟩ → 0 극한에서만 정량적이다."
