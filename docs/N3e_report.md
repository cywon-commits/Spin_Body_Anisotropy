# N3e 보고: 직접 측정한 C₃ 축 기울기로 한 Debye–Waller 보정 (2026-11-19)

## 결론
- **사전 등록 판정: 미충족.** s = 0.03에서는 R = T_Υ^full / T_eff^R = 0.988 ± 0.040으로 기준을 만족한다. 그러나 s = 1에서는 R = 1.094 ± 0.002로 유효 모형이 전체 모형보다 9% 낮다(과보정). "두 s 모두 5% 이내" 기준을 만족하지 못한다 [추측: 전체 모형 평형 미달, 오차는 두 시작 폭의 절반].
- **기울기 직접 측정 [수치확인, 측정량].** T_Υ^full에서 잰 ⟨θ²⟩는 s = 1에서 0.0973 (무작위 0.0969, 정렬 0.0978), s = 0.03에서 0.0261 (0.0249, 0.0273)이다. N3d의 K 기반 값(0.0878, 0.0206)보다 각각 11%, 27% 크다. K = Σn_α⁴는 정적 변형 때문에 기울기를 낮게 잰 것이다.
- **N3d 일치의 재해석 [추측].** N3d의 s = 1 일치(R = 1.010)는 두 효과가 상쇄된 결과로 보인다. K 기반 θ²가 낮게 잰 효과와, 선형 DW 인자 1 − κθ²가 과하게 줄이는 효과다(J₁의 κθ² ≈ 0.58). 선형 인자는 κθ² ≪ 1에서만 유효하다. s = 0.03에서는 κθ² ≈ 0.16이고 일치가 유지된다.
- **자기 일관 가우스 예측의 재평가 [수치확인].** 직접 측정한 θ²는 가우스 예측보다 s = 1에서 1.84배, s = 0.03에서 1.28배 크다. N3d에서 s = 0.03이 거의 일치(1.04)했던 것은 K 기반 θ²의 편향 때문이었다. 가우스 이론은 ℓ_Γ < 1에서도 기울기를 약 30% 낮게 예측한다.
- **재현성 [수치확인].** 같은 시드로 다시 돌린 전체 모형의 T_Υ는 이전 값(N3, N3s)과 정확히 같다. 측정은 연쇄를 바꾸지 않는다.

판정 기준은 `docs/N3e_analysis_plan.md` (생산 전 `b9ae4a9`), 분석은 `scripts/n3e_analysis.py`, 결과는 `data/n3e/`다.

## 3. 해석 [추측]과 다음 단계
- **기울기 요동이 결손의 원인이라는 점은 지지된다.** 보정 크기가 결손 크기와 같은 차수이고, ℓ_Γ가 작아질수록 일치가 좋아진다. 다만 정량적 보정식은 정해지지 않았다.
  - 선형 DW 인자는 κθ² ~ 0.6에서 과보정한다. 지수형 e^{−κθ²} (J₁: 0.56 대 선형 0.42)이나 θ 분포 전체를 쓰는 평균 ⟨d^l_{mm}(θ)⟩ (가우스 가정 없이 측정 분포로)이 후보다. 이 형태는 사전 등록되지 않았으므로 여기서 시험하지 않았다.
  - 가우스 기울기 이론은 측정 기울기를 ℓ_Γ < 1에서도 약 30% 낮게 준다. 비조화 항과 체 내부 변형과의 결합이 후보다.
- **제안:**
  - (a) 측정한 θ 분포로 ⟨d^l_{mm}(θ)⟩를 직접 계산해 결합 인자로 쓰는 보정을 사전 등록 후 시험한다. 저장된 θ² 열 대신 체별 분포 기록이 필요하다.
  - (b) 원고는 "기울기 요동의 Debye–Waller 감소가 결손의 주원인이며, 선형 인자는 ℓ_Γ ≲ 1 (κθ² ≲ 0.2)에서 5% 안에서 맞는다"로 서술한다.
