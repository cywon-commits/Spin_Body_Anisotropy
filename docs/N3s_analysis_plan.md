의뢰자 검토(2026-11-12)에 따른 N3 목표 변경이다. a₄ = −0.02, K = 2, J = 1을 고정하고, 체 사이 결합을 (zG, zH₄) = s·(0.08, 0.80), s ∈ {1, 0.3, 0.1, 0.03}로 줄인다. ρ ∝ s이므로 ℓ_Γ = √(ρ/|Γ|)가 4.5 → 0.8로 줄어, theory_summary P10 (수정판)의 적용 조건 ℓ_Γ ≲ 1을 시험한다.

## 3. 생산 실행
- **전체 모형:** s ∈ {0.3, 0.1, 0.03} × L ∈ {16, 24} × {무작위, 정렬} 시작.
  - 창은 [0.84 T₀, 1.14 T₀], T₀ = 0.0300, 0.0110, 0.0040이고 등간격이다 (s = 1 창과 같은 상대 폭).
  - 복제본은 L = 16에서 28개, L = 24에서 40개. 열평형 3000 + 측정 20000 스윕.
  - s = 1은 N3의 zH₄ = 0.80 무작위 실행(L = 16, 24, 같은 설정)을 다시 쓰고, 정렬 시작만 추가한다.
- **유효 모형:** 각 s의 이완 결합으로 L = 16, 24, 32, 64. s = 1은 N3의 `eff_zH4_0.80`을 쓴다.
- **비용 추정 (실행 전):** 전체 모형 14개 약 6 코어-시간, 유효 모형 12개 약 6 코어-시간. 합계 약 12 코어-시간, 벽시계 2–3시간이다.

## 4. 보고량과 판정
- **T_eff(s):** 유효 모형의 T_I (Binder 외삽, x = 2.75)와 T_KT (WM) 중 높은 쪽. 오차는 결합 잭나이프로 구한다.
- **T_c^full(s, L, 시작):** 두 가지를 쓴다.
  - (i) T_Υ: 온도별 Υπ/(2T)가 1을 지나는 마지막 온도. 시뮬레이션 온도 사이 선형 보간이며, 재가중하지 않는다 (비평형 자료라서).
  - (ii) T_C: 온도별 C의 최댓값 온도. 이웃 세 점 포물선 보간.
- **전체 모형 값과 오차:** 가장 큰 L(= 24)에서 무작위와 정렬 값의 평균을 중심으로 한다. 오차는 두 시작이 감싸는 폭의 절반이며, 폭 자체도 보고한다. 등급은 [추측]이다 (평형 기준 미달 예상).
- **비율:** R_Υ = T_Υ^full / T_eff, R_C = T_C^full / T_eff.
- **⟨K⟩:** T_Υ^full의 0.9배와 1.1배, 그리고 T_Υ^full 자체에서 (L = 24, 두 시작 평균). ℓ_Γ와 Γ/T_eff도 함께 보고한다.
- **사전 등록 판정 (s = 0.03):** |R_Υ − 1| ≤ 0.05이고 T_Υ^full에서의 ⟨K⟩ ≤ 0.36이면 "ℓ_Γ ≲ 1에서 유효 모형이 전체 모형을 대표"로 판정한다.
  - 주 지표는 R_Υ다. s < 1에서 유효 모형의 높은 쪽 전이가 KT이고, σ 지표는 동역학적으로 얼기 때문이다.
  - R_C는 보고만 한다.
- **예측:** R_Υ가 s가 줄수록 단조 증가해 1에 다가간다.
