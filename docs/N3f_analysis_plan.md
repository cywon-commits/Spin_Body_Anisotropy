# N3f: 상대 기울기의 정확한 Debye–Waller 평균 — 사전 고정 (2026-11-19, 생산 실행 전)

의뢰자 검토(2026-11-19)에 따른 N3의 마지막 시험이다. 결과와 무관하게 N3를 여기서 닫고 N4로 간다.

## 1. 물리
- 체 사이 퍼텐셜은 회전 불변이라 두 체의 공통 회전은 결합 에너지를 바꾸지 않는다.
- 상대 회전 R_a⁻¹R_b의 Euler 분해에서 D^l_mm = e^{−im(α+γ)} d^l_mm(β)다. α + γ는 상대 비틀기(ψ 차이)로 유효 모형에 이미 들어 있고, β는 두 체의 C₃ 축 사이 각이다.
- 따라서 결합의 보정 인자는 결합 평균 ⟨d^l_mm(β_ab)⟩다.
- N3d/N3e의 체별 공식은 이웃 기울기 상관 C_nn = 0을 가정한 것이다. ℓ_Γ = 4.5인 s = 1에서 과보정한 방향과 맞는다.

## 2. 측정 (`sbaniso.fullmodel`)
- **축:** 각 체의 C₃ 축 ĉ (`c3_axis`, Kabsch 맞춤, +z 쪽으로 부호를 정함).
- **결합 평균** (x, y 결합 전부, 10 스윕마다): ⟨d³₀₀(β)⟩ = ⟨P₃(cos β)⟩, ⟨d³₃₃(β)⟩ = ⟨cos⁶(β/2)⟩, ⟨d⁴₃₃(β)⟩ = ⟨cos⁶(β/2)(4cos β − 3)⟩, ⟨θ_a·θ_b⟩ (θ = (ĉ_x, ĉ_y)). β = arccos(ĉ_a·ĉ_b)다.
- **체별:** ⟨θ²⟩ = ⟨1 − ĉ_z²⟩. 온도별 β 히스토그램(90칸, 0–π)을 누적하고, C_nn = ⟨θ_a·θ_b⟩/⟨θ²⟩다.
- **단위 시험** (`tests/test_fullmodel.py`):
  - 작은 β 전개 1 − 3β², 1 − 0.75β², 1 − 2.75β².
  - 독립 Wigner small-d 구현과 일치.
  - 공통 기울기에서 인자 1.
  - σ가 뒤집힌 체도 ĉ_z > 0.
  - 기울기 없는 균일 상태에서 인자 1.
- **실행:** N3e의 전체 모형 실행(s ∈ {1, 0.03}, L = 24, 무작위·정렬)을 같은 시드로 다시 돌린다. 연쇄가 같으므로 T_Υ^full이 그대로 재현돼야 한다.

## 3. 보정 결합과 유효 모형
- **결합:** J₁^R = J₁⟨d³₀₀⟩, J₂^R = J₂⟨d³₃₃⟩, J₄^R = J₄⟨d⁴₃₃⟩.
  - 각 평균은 온도별 결합 평균(NaN 제외)을 T_Υ^full에서 선형 보간하고, 무작위·정렬을 평균한 값이다.
  - J는 `data/n3s/params.json`의 이완 결합이다.
- **유효 모형:** L ∈ {16, 24, 32, 64}, 측정 40000 스윕.
  - 창은 L = 16 예비 실행(넓은 창, 결과를 판정 전에 봄, 공개)의 Υ 교차와 U₄ = 0.45 평균 T_mid로 [0.80, 1.20] × T_mid.
  - 복제본 16, 20, 24, 40개.
- **비용 추정:** 전체 모형 4개 약 3.5 코어-시간, 유효 모형 8개 약 3 코어-시간.

## 4. 판정
- **기준:** s = 1과 0.03 모두에서 |T_Υ^full / T_eff^R − 1| ≤ 0.05.
  - T_eff^R = max(T_I, T_KT), N1 방법과 결합 잭나이프.
  - T_Υ^full은 L = 24 두 시작 평균, 오차는 두 시작 폭의 절반. N3e와 같다.
- **보고:** C_nn, β 분포, N3e (체별 인자)와의 비교, 같은 L (L = 24) 비교.

## 5. 원고 문구 (미리 고정)
- **통과:** "상대 기울기의 정확한 Debye–Waller 평균으로 줄인 유효 모형이 ℓ_Γ = 0.8–4.5에서 전체 모형을 5% 안에서 재현한다."
- **실패:** "기울기 요동의 Debye–Waller 감소가 결손의 주원인이며, 선형 인자는 κθ² ≲ 0.2에서 5% 안에서 맞는다. 상대 기울기 평균으로도 s = 1의 차이가 남아, 결합 외 효과(체 변형·결함)를 시사한다."
