# N3e: 직접 측정한 C₃ 축 기울기로 Debye–Waller 보정 — 사전 고정 (2026-11-19, 생산 실행 전)

의뢰자 검토(2026-11-19)에 따른 작업이다. N3d의 ⟨θ²⟩ = 0.75(⟨K⟩ − 1/3)에는 정적 변형이 섞여 있다. K = Σn_α⁴의 최솟값은 1/3인데 바닥상태가 K₀ = 0.324를 준 것은, 변형된 체에서 S₀ + S_α로 만든 축이 정규직교가 아니기 때문이다. 기울기를 직접 재는 관측량으로 바꿔 DW 보정을 다시 시험한다.

## 1. 관측량 (`sbaniso.fullmodel.c3_tilt2`)
- **정의:** 이상적 정사면체를 각 체의 네 스핀에 가장 잘 맞는 고유 회전으로 맞춘다 (Kabsch). 라벨 키랄성은 det Σᵢ Sᵢ Vᵢᵀ의 부호로 고른다. ĉ₃는 맞춘 꼭짓점 방향 중 z에 가장 가까운 것이고, θ² = 1 − (ĉ₃·ẑ)²다. 측정 열은 `timeseries/extra[..., 2]`로, 10 스윕마다 기록하고 나머지는 NaN이다.
- **단위 시험** (`tests/test_fullmodel.py`):
  - 정적 변형만 있는 T = 0 바닥상태 (s = 1, 0.03)에서 θ² < 1e−8.
  - 강체를 θ (≤ 0.6 rad)만큼 기울이면 sin²θ를 1e−8 안에서 재현.
  - 라벨 순열과 z축 회전에 불변.
- **한계:** C₃ 축 선들은 70.5° 떨어져 있다. 그래서 35°보다 큰 기울기는 다른 축으로 접혀 θ² ≤ 2/3이 된다. 큰 요동 영역에서는 ⟨θ²⟩를 약간 낮게 잰다.

## 2. 실행
- **전체 모형:** s ∈ {1, 0.03} × L = 24 × {무작위, 정렬}. N3/N3s의 같은 설정과 같은 시드다. 측정은 난수를 쓰지 않으므로 마르코프 연쇄가 이전 실행과 동일하고 θ² 열만 추가된다. 그래서 T_Υ^full이 이전 값과 같은지가 재현성 검사가 된다.
- **θ²(T_Υ^full):** 온도별 ⟨θ²⟩ (NaN 제외 평균)를 T_Υ^full에서 선형 보간하고, 무작위·정렬 평균을 쓴다.
- **보정 결합:** J₁^R = J₁(1 − 6θ²), J₂^R = J₂(1 − 1.5θ²), J₄^R = J₄(1 − 5.5θ²). J는 `data/n3s/params.json`의 이완 결합이다.
- **유효 모형:** 각 s × L ∈ {16, 24, 32, 64}, 측정 40000 스윕.
  - 창은 L = 16 예비 실행(넓은 창, 판정 전에 결과를 봄, 공개)의 Υ 교차와 U₄ = 0.45의 평균 T_mid로 [0.80, 1.20] × T_mid를 쓴다.
  - 복제본은 16, 20, 24, 40개.
- **비용 추정:** 전체 모형 4개 약 3.3 코어-시간, 유효 모형 8개 약 3 코어-시간. 합계 약 6.5 코어-시간이다.

## 3. 판정
- **기준:** s = 1과 0.03 모두에서 |T_Υ^full / T_eff^R − 1| ≤ 0.05이면 "직접 측정한 기울기의 Debye–Waller 보정 유효 모형이 전체 모형을 대표"로 판정한다.
  - T_eff^R = max(T_I, T_KT)이고, N1 방법과 결합 잭나이프를 쓴다.
  - 오차는 두 시작 폭의 절반이다. 판정은 중심값으로 한다.
- **보고:** 같은 L 비교 (L = 24)와, 새 θ²와 N3d의 K 기반 θ²의 비교.

## 4. 보조: 자기 일관 예측 (판정 아님, 적용 범위 ℓ_Γ ≲ 1)
- **식:** a = T_eff/ρ (보정 없는 유효 모형, N3s), g(ℓ_Γ) = ρ ∫_BZ d²k/(2π)² · 2/(ρk̂² + 8|Γ|/3), κ = 지배 결합의 DW 계수 (T_I이면 J₁의 6, T_KT이면 J₄의 5.5)로 두면 다음과 같다.

  ⟨θ²⟩ = a·g / (1 + a·κ·g),  T_c = T_eff(1 − κ⟨θ²⟩)

- **비교:** 네 s에서 T_Υ^full과, θ² 측정값(s = 1, 0.03은 새 관측량, 0.3과 0.1은 N3d의 K 기반 값임을 표시)과 비교한다.
