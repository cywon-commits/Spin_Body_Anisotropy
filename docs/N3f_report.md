# N3f 보고: 상대 기울기의 정확한 Debye–Waller 평균, 그리고 N3 종료 (2026-11-19)

## 결론
- **사전 등록 판정: 미충족.** s = 0.03에서는 R = T_Υ^full / T_eff^R = 0.969 ± 0.039로 기준을 만족한다. s = 1에서는 R = 0.801 ± 0.002로, 유효 모형이 전체 모형보다 25% 높다(과소보정). "두 s 모두 5% 이내" 기준을 만족하지 못한다 [추측: 전체 모형 평형 미달, 오차는 두 시작 폭의 절반]. 유효 모형 8개는 모두 평형을 통과했다.
- **원고 문구 (사전 고정, 실패 쪽):** "기울기 요동의 Debye–Waller 감소가 결손의 주원인이며, 선형 인자는 κθ² ≲ 0.2에서 5% 안에서 맞는다. 상대 기울기 평균으로도 s = 1의 차이가 남아, 결합 외 효과(체 변형·결함)를 시사한다."
- **이웃 기울기 상관 [수치확인, 측정량].** C_nn = ⟨θ_a·θ_b⟩/⟨θ²⟩는 s = 1에서 0.315, s = 0.03에서 0.104다. 체별 공식(C_nn = 0 가정)이 s = 1에서 과보정한 이유가 이것이다.
  - 상대 기울기로 바꾸면 J₁ 인자가 0.416 → 0.678, J₄ 인자가 0.465 → 0.701로 약해진다.
  - 그 결과 s = 1의 R은 1.094(N3e)에서 0.801로 반대쪽으로 넘어간다. 보정 없는 값은 0.603이다.
- **s = 1에서 R이 세 처방 사이를 오간다.** 0.603 (보정 없음) → 1.094 (체별) → 0.801 (상대). 결합의 Debye–Waller 감소만으로는 s = 1 (ℓ_Γ = 4.5)의 전체 모형을 정량적으로 설명하지 못한다. s = 0.03 (ℓ_Γ = 0.77)에서는 세 처방 중 두 보정이 모두 5% 안이다 (0.988, 0.969).
- **재현성 [수치확인].** 같은 시드의 전체 모형 T_Υ가 N3/N3s/N3e와 정확히 같다.

판정 기준은 `docs/N3f_analysis_plan.md` (생산 전 `0cd297d`), 분석은 `scripts/n3f_analysis.py`, 결과는 `data/n3f/`다.

## 2. 해석 [추측]
- **s = 0.03 (ℓ_Γ < 1):** 기울기가 작고(중앙값 9–11°) 이웃 상관도 약해, 체별·상대 어느 처방으로도 5% 안에서 맞는다. 이 영역에서 "유효 모형 + 기울기의 Debye–Waller 감소"가 전체 모형을 대표한다는 결론은 N3d, N3e, N3f에서 일관된다.
- **s = 1 (ℓ_Γ = 4.5):** 결합 평균 ⟨d^l_mm(β)⟩는 결합 에너지의 평균 감소는 정확히 주지만, 남는 25%를 설명하지 못한다. 남는 효과로 다음을 본다.
  - (i) 큰 기울기(8%가 35° 이상)에서 체 프레임이 잘 정의되지 않는 효과와 체 변형.
  - (ii) 기울기와 σ, ψ의 결합: β와 위상 요동의 상관을 무시했다.
  - (iii) 축 기울기 결함.

  사전 고정한 실패 문구의 "결합 외 효과(체 변형·결함)"가 이것이다.
- **처방의 순서:** 체별 공식은 C_nn을 무시해 과보정했고, 상대 기울기 평균은 결합 에너지만 바꿔 과소보정했다. 정답은 그 사이에 있다.
