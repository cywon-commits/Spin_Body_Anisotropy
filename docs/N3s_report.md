# N3 변경 목표 보고: 결합 축소 s와 유효 모형의 적용 조건 (2026-11-13)

## 결론
- **사전 등록 판정: 미충족.** s = 0.03 (ℓ_Γ = 0.77)에서 R_Υ = T_Υ^full / T_eff = 0.866 ± 0.035로, 기준 |R_Υ − 1| ≤ 0.05를 만족하지 못한다. 전이 온도에서의 ⟨K⟩ = 0.361도 기준 0.36을 근소하게 넘는다. 따라서 "ℓ_Γ ≲ 1에서 유효 모형이 전체 모형을 대표"는 이 자료로 확인되지 않는다 [추측: 전체 모형 평형 미달].
- **예측된 경향은 확인 [추측].** R_Υ가 s가 줄수록 단조 증가한다: 0.603 → 0.692 → 0.773 → 0.866. ⟨K⟩도 1/3 쪽으로 단조 감소한다: 0.45 → 0.42 → 0.39 → 0.361. ℓ_Γ가 줄수록 축이 더 고정되고 유효 모형에 다가가는 방향은 맞다.
- **불일치는 유한 크기·평형 문제보다 크다.** s = 0.03에서 정렬 시작(위쪽 한계)만 써도 R_Υ = 0.901이다. 또 모든 s에서 전체 모형의 T_Υ가 L = 16 → 24로 줄어드는 쪽이라, L → ∞ 비율은 더 작아질 것이다. ℓ_Γ = 0.77로는 아직 부족하다.

판정 기준은 `docs/N3s_analysis_plan.md` (생산 실행 전 `57a7d8a`로 커밋), 분석은 `scripts/n3s_analysis.py`, 결과는 `data/n3s/n3s_summary.json`, 그림은 `figures/n3s_ratio.png`다.

## 3. 보조 관찰 (사전 등록 아님) [추측]
- **수렴 속도:** 1 − R_Υ = 0.397, 0.308, 0.227, 0.134는 |Γ|/T_eff = 0.56, 1.84, 5.5, 18.3에 대해 대략 ln(|Γ|/T_eff)에 선형으로 줄어든다 (단위 ln당 약 0.075). 이대로 외삽하면 R_Υ ≈ 0.95에 이르려면 |Γ|/T ≈ 60 (s ≈ 0.01, ℓ_Γ ≈ 0.45), R_Υ ≈ 1에는 |Γ|/T ~ 10² (s ≈ 0.005)이 필요하다. 거듭제곱(1 − R ∝ (T/|Γ|)^0.3)으로도 비슷하게 맞아 형태는 정하지 못한다.
- **원인 후보:** ℓ_Γ < 1에서도 남는 결손 13%는 결함 가둠만으로는 설명되지 않는다. 열적 축 기울기 요동(⟨K⟩ − 1/3 ≈ 0.03, rms 기울기 약 0.13 rad)이 평면 내 결합을 깎는 Debye–Waller형 감소가 후보다. 이것은 T/|Γ|의 거듭제곱으로 줄어야 하는데, 관측된 감소는 그보다 느리다. 무작위 시작의 얼어붙은 σ 영역이 T_Υ를 낮추는 효과도 섞여 있다. 정렬 시작만 보면 R_Υ = 0.603, 0.695, 0.781, 0.901이다.
- **P10 문구에 대한 함의:** "ℓ_Γ ≲ 1"은 필요조건으로 보이나 충분조건이 아니다. 자료는 |Γ|/T ≫ 1 (적어도 수십)이 함께 필요함을 시사한다. P10을 고칠지는 의뢰자가 정할 문제라 이 보고서에서는 고치지 않았다.

## 4. 남은 일과 제안
- **s를 더 줄이기:** s = 0.01, 0.003 (ℓ_Γ = 0.45, 0.24)에서 같은 측정을 하면 R → 1 수렴 여부를 직접 볼 수 있다. 다만 σ가 더 얼어붙어 무작위·정렬 폭이 넓어질 것이다. 비용은 점당 약 2 코어-시간이다.
- **근본 해결:** 체 뒤집기(σ)와 체 회전을 위한 클러스터 이동이다 (이번 범위 밖).
- **원고 서술 제안:** "a₄ = −0.02에서 체 사이 결합을 줄이면 전체 모형의 전이 온도가 유효 모형 예측에 단조로 다가가며 (ℓ_Γ = 4.5 → 0.8에서 0.60 → 0.87), 유효 모형은 |Γ| ≫ ρ, T인 극한에서만 정량적이다."
