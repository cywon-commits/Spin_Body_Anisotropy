# N3 보고: 전체 스핀체 모형 (T2) (2026-11-12)

## 결론
- **polyspin 이방성 확장 완료 [수치확인].** Paper I 저장소의 별도 브랜치 `anisotropy-extension`에 단일 스핀 이방성 V = Σᵢ[a₂P₂(ẑ·Sᵢ) + a₄P₄(ẑ·Sᵢ)]를 넣고 태그 `v0.2.0-aniso`(`edda213`)를 붙였다.
  - Paper I의 기존 테스트 157개(느린 통계 테스트 포함)와 새 테스트 13개가 모두 통과했고, 돌연변이 검사도 모두 잡혔다.
  - Paper I의 기본 브랜치에는 병합하지 않았다 (CLAUDE.md 규칙). 이 저장소는 그 태그를 `fullmodel` 의존성으로 고정했다.
- **Γ 공식 확인 [수치확인].** 방향을 고정한 단일 체 완화가 E(n̂) = c − ΓΣn_α⁴를 재현한다.
  - a₄ = −0.02에서 0.6% 이내로 맞는다.
  - ±a₂ 평균은 0.1% 이내로 맞는다.
  - 남는 차이는 진폭에 선형으로 줄어드는 다음 차수 항이다.
- **r_eff 재계산 [수치확인].** 완화를 포함해 zH₄ = 0.72, 0.80, 0.88에서 r_eff = 3.677, 4.050, 4.418, J₁/J₂ = 1.162, 1.154, 1.145를 얻었다 (TASK 예상 3.6, 4.05, 4.5).
- **TASK 판정: 불일치.** 전체 모형이 TASK 매개변수(a₄ = −0.02)에서 유효 모형을 대표하지 않는다.
  - 전체 모형의 전이 온도 T_c ≈ 0.080–0.088 J는 같은 (이완) 결합의 유효 모형 예측 T_I, T_KT = 0.130–0.146 J보다 약 40% 낮다. z > 250이고, 무작위·정렬 시작 사이의 이력 폭(0.0015 J)보다 30배 이상 크다 [수치확인].
  - 유효 모형은 zH₄ = 0.80과 0.88 사이에서 Ising–KT 순서가 뒤집히지만(r_eff ≈ 4.11에서 교차), 전체 모형은 세 점 모두 σ 질서와 ψ 준질서가 같은 온도 근처(분해능 약 0.002 J)에서 함께 나타나고 순서 변화가 보이지 않는다 [추측: 평형 미달, 2절].
- **원인 [추측, 근거 있음].** 축 선택 지표 ⟨K⟩ = ⟨Σn_α⁴⟩가 전이 아래에서 0.42, 위에서 0.52–0.53이다 (C₃ 고정은 1/3, 등방은 0.6). C₃ 축이 z에 고정되지 않고 크게 기울어 요동한다. 유효 모형은 축이 고정된다는 전제(|Γ| ≫ T)에서 유도되는데, a₄ = −0.02이면 축 고정 에너지(등방 대비 0.021, C₃–S₄ 차 0.052)가 전이 온도(약 0.085)보다 작다. 기울기 요동이 평면 내 결합을 약 0.6배로 깎은 것으로 본다.
- **평형 미달.** 전체 모형 9개 실행이 모두 평형 기준을 통과하지 못했다 (τ_int 300–1800 스윕, 왕복 2–10회). 위 수치 중 "40% 낮음"은 무작위·정렬 시작이 전이를 좁게 감싸므로 견고하지만, 전이 순서·1차 여부·정확한 T_c는 [추측] 등급이다.

## 2. 전체 모형 계산
- **드라이버** `sbaniso.fullmodel`: polyspin의 PT(단일 스핀, 강체 회전, 겹침 이동)를 쓰고, 측정은 C₃ 유효 모형과 같은 형식으로 저장한다.
  - σ ← q₃₀, e^{iφ} ← q₃₃, e^{iψ} ← q₄₃ (각 체, 실험실 z축, 이상적 C₃ 체에서 크기 1로 정규화)
  - Υ_ψ = ρ_α/9 (z축 비틀기 강성, 이방성에서도 정확)
  - K = Σn_α⁴
  - 그래서 N1 분석 도구를 그대로 쓴다. 측정 정확성은 `tests/test_fullmodel.py`가 확인한다 (다중극, σ와 위상 관계, 강성 대 유한 비틀기).
- **예비 실행에서의 사고와 대책.** 첫 예비 실행 일부가 이방성 없이 돌았다. 이방성을 넣기 전에 컴파일된 `polyspin.pt.run_sweeps`의 numba 캐시가 남아 있었고, numba는 다른 모듈의 피호출 함수가 바뀌어도 호출자 캐시를 무효화하지 않는다. 이상 신호는 a₄ = −0.5에서도 ⟨K⟩ = 0.600(등방)이었던 것이다. 해당 실행을 폐기하고 캐시를 지운 뒤 다시 돌렸다. 드라이버는 이제 시작할 때 PT 엔진의 에너지와 새로 컴파일한 `energy_total`을 비교해, 다르면 실행을 거부한다 (`_check_kernels`).
- **생산 실행** (`configs/n3/full/`, 사전 계획 `docs/N3_analysis_plan.md`):
  - 세 점 × L = 16, 24, 32, 전이 창 [T_c,16 − 0.014, T_c,16 + 0.012]의 등간격 사다리 (복제본 28/40/64)
  - 열평형 3000 + 측정 20000 스윕, 정렬 시작 대조 1개 (zH₄ = 0.80, L = 32)
  - 약 9 코어-시간
- **유효 모형 대조** (`configs/n3/eff/`): 같은 이완 결합에서 L = 16, 24, 32, 64를 돌렸다. 12개 모두 평형 통과 (τ ≤ 2.7, 왕복 ≥ 176).

**전체 모형의 평형 (사전 계획 5절에 따라 등급을 낮춤):**

| 점 | L = 16 | L = 24 | L = 32 |
| --- | --- | --- | --- |
| zH₄ = 0.72 | τ 432, 왕복 6 | τ 872, 왕복 2 | τ 1509, 왕복 4 |
| zH₄ = 0.80 | τ 317, 왕복 8 | τ 859, 왕복 8 | τ 1786, 왕복 7 |
| zH₄ = 0.88 | τ 305, 왕복 10 | τ 1382, 왕복 7 | τ 1743, 왕복 5 |

교환 수락은 모두 0.35 이상이다. 문제는 교환이 아니라 각 온도 안의 느린 배향 동역학(국소 이동만 있음)이다. 정렬 대 무작위 시작 (zH₄ = 0.80, L = 32)은 max|z| = 10.7, χ²/자유도 = 6.7로 일치하지 않는다. 다만 차이는 전이 바로 아래 좁은 구간(0.077–0.086)에만 있고, Υ = 2T/π 위치는 0.0824 (무작위) 대 0.0837 (정렬)로 전이를 0.0015 J 폭으로 감싼다. 전이 위(T ≥ 0.087)에서는 두 시작이 일치한다.

## 3. 판정
**(1) TASK 판정: 유효 모형과의 일치 → 불일치.** 단위는 J다.

| zH₄ (r_eff) | 유효 T_I | 유효 T_KT | 유효 순서 | 전체 Υ = 2T/π (L = 16, 24, 32) | 전체 C 최댓값 T (L = 16, 24, 32) | 전체 WM T_KT |
| --- | --- | --- | --- | --- | --- | --- |
| 0.72 (3.68) | 0.13652(2) | 0.13024(4) | Ising 위 (+0.0063) | 0.0799, 0.0795, 0.0791 | 0.0810, 0.0810, 0.0808 | 0.0781(2) |
| 0.80 (4.05) | 0.13952(2) | 0.13859(3) | Ising 위 (+0.0009) | 0.0844, 0.0839, 0.0827 | 0.0854, 0.0852, 0.0847 | 0.0825(1) |
| 0.88 (4.42) | 0.14171(2) | 0.14626(3) | KT 위 (−0.0046) | 0.0887, 0.0879, 0.0870 | 0.0901, 0.0898, 0.0886 | 0.0862(1) |

- **전체 모형의 T_I:** Binder 교차를 정의할 수 없었다. 전이 아래에서 U₄가 2/3에 붙어 있다가 전이에서 한꺼번에 떨어지고, L = 32의 비평형 때문에 교차가 흩어진다.
- **판정 근거:** 전체 모형의 T_KT와 C 최댓값 온도는 유효 모형 값보다 0.05–0.06 J (약 40%) 낮다. 순서도 비교할 수 없다. 전체 모형에서는 Υ가 무너지는 온도가 C 최댓값보다 0.001–0.003 J 아래로, 세 점 모두 같은 쪽이다.
- **유효 모형 자체의 교차:** zH₄ = 0.80과 0.88 사이 (r_eff ≈ 4.11)다. 같은 J₁/J₂ ≈ 1.15에서의 해석 예측 r_× ≈ 4.07 (theory_summary)과 가깝다 [수치확인].

**(2) 공동 전이인가.** 가장 큰 L에서 U₄ 교차 평균, Υ 교차, C 최댓값 온도가 3σ 안에 있지 않아 사전 기준상 "공동 아님"이다. 하지만 세 지표의 차이는 0.001–0.003 J이고, 이 실행들이 평형 미달이라 오차 막대가 실제 불확실성을 담지 못한다. 결론은 "σ와 ψ 질서가 0.003 J 안에서 함께 나타남"이다 [추측].

**(3) 1차 전이인가: 판정 불가.**
- 재가중 에너지 히스토그램은 모든 크기에서 단봉이다 (비 1.0).
- C 최댓값은 L = 16 → 24에서 늘고 L = 32에서 줄어 단조가 아니다 (비평형). C_max/L²는 감소한다.
- 사전 기준상 zH₄ = 0.80에서만 "C_max ∝ L² 맞춤 기각 안 됨, ln L 기각"이 성립했지만, L = 32 값이 신뢰할 수 없으므로 1차 판정을 하지 않는다 [추측].
- 1차 징후 (L = 16의 교환 0.01, C 봉우리 24–31, U₄ < 0)는 있으나 결론을 낼 수 없다.

**(4) 축 선택.** 세 점 모두 ⟨K⟩가 T_c − 0.01에서 0.42, T_c + 0.01에서 0.52–0.53, 전이에서 급변한다. T = 0 바닥상태는 0.340 (C₃ ∥ z)이다. 전이 위에서는 축이 거의 등방(0.6)에 가깝게 요동한다.

## 4. 해석과 권고
- **유효 모형의 적용 범위 [추측].** 유효 모형은 C₃ 축 고정과 강체 체를 전제한다. 전체 모형에서 축 고정은 축 선택 에너지 |Γ|·O(0.3)와 온도의 비로 정해진다. a₄ = −0.02이면 이 비가 약 0.25로, 축이 고정되지 않은 상태에서 σ, ψ 질서가 생겨야 한다. 이때 배향 질서 전체(축 선택, σ, ψ)가 한꺼번에 생기는 하나의 전이로 보이고, 그 온도는 유효 모형보다 약 40% 낮다.
- **N3 목표를 위한 선택지:** "유효 모형이 전체 모형을 대표"를 보이려면 다음 중 하나가 필요하다.
  - (a) 축이 고정되는 강한 이방성 영역. 예비 실행에서 a₄ = −0.5면 ⟨K⟩ ≈ 0.31–0.42이지만 체가 눈에 띄게 변형된다 (바닥상태 min Sᵢ·Sⱼ = −0.45). 변형을 포함한 유효 결합 재계산이 필요하다.
  - (b) 기울기 요동을 포함한 유효 모형. 결합의 열적 재규격화를 유도해야 한다.
  - (c) 원고에서 T2를 "a₄ = −0.02에서는 대표하지 않음, 적용 조건 |Γ| ≫ T_×"로 서술.

  어느 쪽인지는 의뢰자가 정할 문제다.
- **전체 모형 평형:** L = 32에서 기준을 맞추려면 현재 스윕의 약 20배가 필요하다 (점당 약 30 코어-시간). σ 뒤집기와 체 회전을 위한 클러스터 이동을 polyspin에 넣는 것이 근본 해결책이다.
